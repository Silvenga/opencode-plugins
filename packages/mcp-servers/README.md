# @slvnco-opencode/mcp-servers

Configure local and remote MCP servers.

## Configuration

```jsonc
{
  "plugins": [
    {
      "package": "@slvnco-opencode/mcp-servers",
      "options": {
        "servers": {
          "docs": {
            "type": "remote",
            "url": "https://mcp.example.com/mcp"
          }
        }
      }
    }
  ]
}
```
